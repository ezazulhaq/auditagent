# AuditAgent v2.3.1 Release Notes

**Release Date:** October 31, 2026

AuditAgent 2.3.1 fixes a state synchronization issue on the Findings tab where security findings with merged GitHub pull requests remained in `PR_OPEN` status after clicking the refresh button. It also ensures terminal finding states take precedence over stale in-memory run caches, preserves active tab selection on manual refresh, and updates the drawer timeline to reflect merged PR status.

---

## 🚀 Bug Fixes & Enhancements

### 1. Findings Refresh & Run State Synchronization (`useRemediationController`)
* **Terminal Status Run Purge**: When refreshing findings, `refreshReport()` inspects incoming finding statuses. Any finding with a terminal status (`FIXED` or `IGNORED`) is purged from `runs`, `publications`, and `previews` state maps.
* **Selection State Sync**: When a selected finding transitions to `FIXED`, `selectedFinding` is updated in place with the latest status.
* **Transition Notifications**: Dispatches a success notification and info message when a finding transitions from `PR_OPEN` to `FIXED`.
* **Backend Thread Reconciliation**: Polling during an active PR now queries `api.getThread(threadId)` to trigger backend PR state reconciliation, stopping automatically once all PRs are resolved.

### 2. Display Precedence & Filter Accuracy (`FindingsView`, `auditSelectors`)
* **Status Precedence**: In `FindingsView`, terminal finding statuses (`FIXED`, `IGNORED`) are strictly preserved and never overridden by in-memory `runs` state.
* **Filter Consistency**: Updated `filterFindings` to evaluate `runs` and respect terminal statuses so text search and status filter dropdowns accurately match rendered table badges.

### 3. Finding Drawer & Remediation Timeline (`FindingDrawer`)
* **Merged State Banner**: Guarded the pending PR alert so findings marked `FIXED` display `Merged on GitHub · finding fixed` instead of the pending merge prompt.
* **Timeline Completion**: Remediation timeline advances to Step 4 ("Fix merged") when a finding is in `FIXED` status.

### 4. Tab Stability (`App.jsx`)
* **Silent Refresh**: The manual refresh button in the Findings tab passes `silent = true` to prevent unintended redirection to the `report` tab.
