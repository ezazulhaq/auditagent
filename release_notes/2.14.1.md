# AuditAgent v2.14.1 Release Notes

**Release Date:** November 21, 2026

AuditAgent 2.14.1 upgrades core infrastructure and dependencies to Spring Boot 4.2.0, aligns Spring AMQP starters and serialization components with modern Jackson 3 conventions, bumps LangChain4j and LangGraph4j orchestration libraries, and updates JGit.

---

## 🚀 Enhancements & Dependency Modernization

### 1. Spring Boot 4.2.0 & Spring AMQP Modularization
* **Dedicated RabbitMQ Starter (`spring-boot-starter-rabbitmq`)**:
  * Migrated from `spring-boot-starter-amqp` (repurposed in Spring Boot 4.2 as a generic AMQP 1.0 starter) to the dedicated `spring-boot-starter-rabbitmq` artifact.
  * Restores auto-configuration (`RabbitAutoConfiguration`), connection factories, and `RabbitTemplate` for AMQP 0.9.1 operations.
* **Modernized JSON Message Converter (`RabbitMqConfig.java`)**:
  * Upgraded `MessageConverter` bean from deprecated `Jackson2JsonMessageConverter` to `JacksonJsonMessageConverter`, aligning with Jackson 3 (`tools.jackson.databind.json.JsonMapper`) and eliminating compile-time deprecation warnings.

### 2. Agent Orchestration & Core Dependencies
* **LangChain4j (`1.24.0`)**: Updated core LLM communication models, tool definitions, and token auditor dependencies.
* **LangChain4j OkHttp Client (`1.24.0-beta34`)**: Synchronized client builder factory SPI registration.
* **LangGraph4j (`1.9.9`)**: State graph evaluation, multi-agent supervisor node, and milestone checkpoint serialization.
* **Eclipse JGit (`7.8.1.202611041320-r`)**: Upgraded Git transport, ref management, and credentials provider.

### 3. Complete DuckDB Code & Legacy Artifact Retirement
* **Removal of Deprecated Stubs**: Safely removed `DuckDbCheckpointSaver.java` and `DuckDbKnowledgeBaseService.java` following full PostgreSQL consolidation.
* **Direct PostgreSQL Checkpoint Saver**: Updated `RemediationWorkflowGraph` and test suites to bind directly to `DatabaseCheckpointSaver`.
* **Configuration Cleanup**: Removed unused legacy `auditagent.database.path` properties across `application-local.yaml`, `application-dev.yaml`, `application-example.yaml`, `application-test.yaml`, and `.env.example`.
* **Playbook Modernization**: Modernized `.auditagent/skills/db-manager/SKILL.md` to reflect PostgreSQL database persistence.
