# AuditAgent v2.13.0 Release Notes

**Release Date:** November 17, 2026

AuditAgent 2.13.0 implements **Phase 5: Workspace Storage Decoupling & Host Sandbox Hardening**, completing the decoupling of worker and ingress/web pods and isolating untrusted repository build and test executions inside containerized sandboxes. This release introduces stateless workspace reconstruction using remote patch bundles stored in object storage (Supabase Storage / local fallback) and relational audit tables (`run_changes`), allowing worker nodes to immediately clean up disk clones after remediation verification while ingress web nodes reconstruct workspaces on-demand at PR publication time. Additionally, `ContainerizedProcessRunner` brings ephemeral, resource-bounded Docker sandbox execution with network restriction, memory/CPU quotas, Linux capability dropping, and strict host secret stripping.

---

## 🚀 New Features & Enhancements

### 1. Stateless Patch Bundles & Workspace Storage Decoupling
* **`PatchBundle` Serialization & Storage (`PatchBundleService.java`)**:
  * Introduces the `PatchBundle` domain record containing unified git diffs, changed file lists, SHA-256 file hashes, text file contents, base SHA, and remediation summaries.
  * Implemented `PatchBundleService` to serialize and upload verified remediation patch bundles to Supabase Storage (`runs/{runId}/patch-bundle.json` and `runs/{runId}/patch.diff`) and mirror file modifications into the relational `run_changes` table.
  * Decouples worker pods from long-lived filesystem storage: worker pods can immediately delete their workspace clone once verification passes.
* **On-Demand Publication Workspace Reconstruction (`PublicationNode.java`)**:
  * Refactored `PublicationNode` to eliminate hard reliance on `run_publications.workspace_path` across distinct cluster nodes.
  * When executing on a node where the local workspace directory is missing (or when `stateless-workspaces: true` is configured), `PublicationNode` automatically downloads the patch bundle from object storage, clones the exact repository commit at `baseSha`, applies the patch bundle, commits, and publishes the Pull Request.
  * Ensures ephemeral publication workspaces are guaranteed to be cleaned up in a `finally` block, leaving zero leaked disk clones.
* **Proactive Workspace Lifecycle Cleanup (`RejectNode.java`, `ApprovalReadyNode.java`)**:
  * Added automated workspace deletion in `ApprovalReadyNode` when `statelessWorkspaces` is active.
  * Updated `RejectNode` to clean up any remaining workspace files when a human user rejects a proposed remediation.

### 2. Ephemeral Containerized Sandbox Execution (`ContainerizedProcessRunner.java`)
* **Bounded Ephemeral Docker Execution**:
  * Implemented `ContainerizedProcessRunner` extending `ManagedProcessRunner` with `@Primary` Spring injection.
  * When `auditagent.agent.sandbox-enabled: true`, untrusted build and verification commands (`mvn`, `gradle`, `pytest`, `npm test`) execute inside an isolated container runner (`docker run --rm`).
  * Enforces strict resource quotas:
    * `--memory=2g` (configurable via `auditagent.agent.sandbox-memory-limit`)
    * `--cpus=2.0` (configurable via `auditagent.agent.sandbox-cpu-limit`)
    * `--network=none` for complete offline build execution without external exfiltration paths
    * `--security-opt=no-new-privileges` to prevent privilege escalation
    * Dropped dangerous Linux capabilities (`--cap-drop=CAP_NET_RAW`, `--cap-drop=CAP_SYS_ADMIN`)
    * Ephemeral writable `/tmp` filesystem (`--tmpfs /tmp:rw,noexec,size=512m`)
    * Workspace volume mount and working directory strictly bounded to the canonical workspace real path.
* **Zero Host Secret Leakage**:
  * Hardened against host secret leakage: sensitive environment variables (`SUPABASE_SERVICE_KEY`, `OPENAI_API_KEY`, `GITHUB_TOKEN`, `AWS_SECRET_ACCESS_KEY`, etc.) are stripped and never forwarded into sandbox containers.
* **AgentToolService Integration**:
  * Injected `ManagedProcessRunner` into `AgentToolService`, unifying process execution across scanner analysis and agent build/test tools.
