# AuditAgent v2.14.5 Release Notes

**Release Date:** November 28, 2026

AuditAgent 2.14.5 resolves the `"No documentation found."` issue in the in-app Documentation viewer by packaging project Markdown guides into the application JAR and Docker runtime images, adding classpath resource fallback in `DocHandler`, and eliminating redundant sidebar fetches.

---

## 🛠️ Bug Fixes & Enhancements

* **In-App Documentation Discovery & Packaging**:
  * Updated `DocHandler` (`src/main/java/com/cb/auditagent/controller/DocHandler.java`) to read deterministically sorted `.md` files from `auditagent.docs.dir` (default `doc`) and fall back to `classpath*:doc/*.md` via `ResourcePatternResolver` when running from an executable JAR or container without a working-directory `doc/` folder.
  * Hardened filename validation against directory traversal (`/`, `\`, `..`, null bytes, non-`.md` filenames) and standardized `text/plain; charset=UTF-8` responses.
  * Configured `pom.xml` to bundle `doc/*.md` under `BOOT-INF/classes/doc/` and updated `Dockerfile` and `Dockerfile.dev` to include `doc/` in both `backend-builder` and `runtime` stages.
* **Frontend Documentation Viewer & Header Menu**:
  * Fixed `DocsSidebar` (`frontend/src/features/docs/DocsSidebar.jsx`) re-fetching `/api/docs` on every document selection by decoupling the fetch effect from `selectedDoc`.
  * Cleaned up `DocsMainPanel` (`frontend/src/features/docs/DocsMainPanel.jsx`) loading and error state transitions when switching or clearing selected documents.
  * Renamed the `"Profile & LLM Keys"` menu item in `AppHeader` (`frontend/src/components/AppHeader.jsx`) to `"API Keys"`.
  * Added automated test coverage in `DocHandlerTest` and `DocsView.test.jsx`.
