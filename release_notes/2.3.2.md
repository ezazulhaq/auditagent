# AuditAgent v2.3.2 Release Notes

**Release Date:** November 1, 2026

AuditAgent 2.3.2 delivers comprehensive frontend interaction performance optimizations, eliminating high click and event reaction latency (~3s lag) across the workspace. It introduces non-blocking deferred syntax highlighting, decouples scan timer intervals from the application root, implements granular row-level memoization with CSS layout containment, schedules UI transitions concurrently via React 19 `startTransition`, and ref-stabilizes event listeners and context providers.

---

## 🚀 Performance Optimizations & Enhancements

### 1. Non-Blocking Syntax Highlighting (`FindingDrawer`, `DiffViewer`)
* **Immediate Frame-1 Paint**: Replaced synchronous Prism execution on drawer mount with `VulnerableCodeViewer`, rendering instant raw monospace code within `<pre><code>` on initial paint (<16ms).
* **Deferred Tokenization**: Defers heavy Prism AST tokenization (290 language grammars) to a secondary `requestAnimationFrame` render phase, completely eliminating 1.5–3.0s main-thread blocking when clicking findings or initiating analysis.

### 2. Scan Elapsed Timer Scoping (`ScanPanel`, `App`)
* **Root Re-render Elimination**: Removed `useScanElapsedSeconds` from root `App.jsx` and scoped the 1-second interval timer directly inside `ScanPanel.jsx`.
* **Isolated Timer Ticks**: Active security scans update only the scan panel duration indicator without triggering full-application re-render cascades every 1,000ms.

### 3. Granular Row Props & Component Memoization (`FindingsView`, `DashboardView`)
* **Row Memoization & Scalar Props**: Wrapped `FindingRow` in `React.memo` and replaced passing the entire mutable `runs` dictionary with a scalar `runStatus` prop, ensuring individual finding updates re-render only the affected row.
* **Selection Handler Stability**: Wrapped `handleToggleSelect`, `handleToggleGroup`, and `handleSelectAllFiltered` in `useCallback`.
* **View Tree Memoization**: Memoized `DashboardView`, `WorkspaceTabs`, `AppHeader`, `DiffViewer`, `GraphTimeline`, `ChatWidget`, `CodeBlock`, and `MessageBubble`.

### 4. Layout Containment & Concurrent Scheduling (`index.css`, `App`)
* **CSS Containment**: Added `.finding-row-contained` applying `content-visibility: auto; contain-intrinsic-size: auto 65px;` to isolate finding rows and prevent DOM mutations from causing page-wide reflows.
* **Transition Scheduling**: Scheduled finding drawer selection (`handleSelectFinding`) and workspace tab navigation (`handleTabChange`) using React 19 `startTransition`, allowing urgent user clicks and typing to interrupt and register instantly.
* **Listener & Context Stabilization**: Ref-stabilized `useKeyboardShortcuts` to attach `window.addEventListener('keydown')` only once on mount, and wrapped `ToastProvider` context value in `useMemo`.
