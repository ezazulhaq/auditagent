# AuditAgent v2.12.0 Release Notes

**Release Date:** November 16, 2026

AuditAgent 2.12.0 delivers the **Vercel ui-sdk Primitives & Agent-Readiness Integration**, modernizing core interactive UI primitives across the application using `@ui-sdk/react` and `@ui-sdk/core`. This release replaces legacy hand-rolled DOM overlays and dropdowns (`CustomSelect`, `Modal`, `ConfirmDialog`, `WorkspaceTabs`, and form checkboxes) with accessible, WAI-ARIA compliant, keyboard-navigable components while maintaining exact caller contracts, backward-compatibility, and the dark DevSecOps visual design. Furthermore, it introduces an automated UI agent bridge with WebMCP registration (`createAgent`, `registerTools`), enabling AI assistants to inspect and safely navigate the interface.

---

## 🚀 New Features & Enhancements

### 1. Vercel ui-sdk Theme Token Mapping & Performance Containment
* **Lightweight `@layer ui-sdk;` Behavioral Containment**:
  * Added top-level `@layer ui-sdk;` in `frontend/src/index.css` before Tailwind imports, providing essential behavioral containment (`[data-slot][hidden]:not([hidden="until-found"]) { display: none !important; }`).
  * Eliminated the heavy 3,300+ line generic `web.css` bundle and its expensive relational `:has()` selectors (`:is(label):has(...)`, `:not([data-slot="field"]):has(...)`), reducing CSS bundle size by 81 kB (37%) and preventing browser style invalidation lag during streaming and DOM updates.
* **Semantic DevSecOps Token Bindings**:
  * Bound ui-sdk variables (`--ui-background`, `--ui-foreground`, `--ui-muted`, `--ui-border`, `--ui-input`, `--ui-primary`, `--ui-ring`, `--ui-radius`, `--ui-font-sans`, `--ui-font-mono`) directly to AuditAgent's CSS custom properties in both dark (`:root`) and light (`html.light`) themes.

### 2. Core Interactive Primitives Modernization & Performance
* **Accessible Select Primitive with Lazy Mounting (`CustomSelect.jsx`)**:
  * Re-implemented with `@ui-sdk/react/select` compound parts (`Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`, `SelectItemIndicator`).
  * Wrapped in `React.memo` with lazy-mounted option items (`open && items.map(...)`), eliminating virtual DOM diffing and `useLayoutEffect` execution for closed dropdowns.
  * Features keyboard up/down arrow navigation, automated focus management, anchor-width popover alignment, and active check indicators.
  * Preserves exact caller interface (`value`, `onChange`, `options`, `disabled`, `placeholder`), guaranteeing 0 regressions for repository and branch selectors.
* **Top-Layer Dialog Modal (`Modal.jsx`)**:
  * Powered by `@ui-sdk/react/dialog` (`Dialog`, `DialogBackdrop`, `DialogContent`, `DialogTitle`, `DialogClose`).
  * Provides top-layer focus trapping, blurred backdrops, accessible Escape dismissal, and outside-press handling for findings breakdown and child views.
* **Confirmation Alert Dialog with Guardrails (`ConfirmDialog.jsx`)**:
  * Built on `@ui-sdk/react/alert-dialog` (`AlertDialog`, `AlertDialogBackdrop`, `AlertDialogContent`, `AlertDialogTitle`, `AlertDialogDescription`, `AlertDialogClose`).
  * Connects `AlertDialogTitle` and `AlertDialogDescription` for immediate assistive technology announcements.
  * Adds `data-agent-confirm` to enforce confirmation barriers for destructive or critical actions.
* **Semantic Workspace Navigation Tabs (`WorkspaceTabs.jsx`)**:
  * Upgraded to `@ui-sdk/react/tabs` (`Tabs`, `TabsList`, `TabsTab`, `TabsTabIcon`).
  * Provides true WAI-ARIA `tablist` and `tab` roles, left/right keyboard arrow navigation, active indicator styling, and live finding/issue counts.
* **Fresh Rescan Switch Toggle & Scan Timer Isolation (`RepoBranchSelector.jsx`)**:
  * Upgraded the "Force fresh rescan" option from a raw HTML checkbox to `@ui-sdk/react/switch` (`Switch`, `SwitchThumb`), supporting Space key toggling and animated state transitions.
  * Memoized `repositoryOptions`, `branchOptions`, and `scannerOptions` with `useMemo`, and isolated the 1-second scanning timer in `ScanActionButton`, ensuring tick updates do not re-render select primitives.

### 3. Agent Bridge & WebMCP Integration (`agentBridge.js`)
* **Autonomous Agent Control Bridge**:
  * Implemented `src/utils/agentBridge.js` connecting `createAgent` and `registerTools` from `@ui-sdk/react/agent`.
  * Enables AI agents to snapshot component state (`agent.snapshot()`), execute UI actions (`agent.act()`), and query controls (`agent.query()`).
  * Integrates WebMCP browser tool registration when `document.modelContext` is present.
  * Honors human-in-the-loop confirmation guardrails (`step.confirm`) before executing marked actions.

### 4. Testing & Verification Suite
* **Testing Library & jsdom Stubs**:
  * Configured required jsdom stubs in `frontend/src/test/setup.js` (`showPopover`, `hidePopover`, `ResizeObserver`, `getAnimations`, `checkVisibility`) and enabled `globalThis.__UI_SDK_STRICT__ = true`.
  * Added `agentBridge.test.jsx` verifying tool metadata, snapshot generation, semantic accessible names, and confirmation attribute presence.
  * Full Vitest test suite passes across all 27 test files (123 / 123 tests passing).
