# AuditAgent v2.9.0 Release Notes

**Release Date:** November 14, 2026

AuditAgent 2.9.0 delivers **Phase 3: AI Framework Consolidation & Pipeline Decomposition**, standardizing the autonomous remediation and conversational intelligence stack exclusively on LangChain4j while decomposing the monolithic `LlmService` into focused, single-responsibility domain services. This release eliminates duplicate Spring AI dependencies and caching layers, introduces reactive token streaming over SSE using LangChain4j `StreamingChatModel`, declaratively registers agent tool specifications, and isolates failure reflections, diff pattern extractions, and token metrics auditing into modular components.

---

## 🚀 New Features & Enhancements

### 1. Complete Spring AI Removal & LangChain4j Standardization
* **Dependency Pruning**:
  * Completely removed `spring-ai-markdown-document-reader`, `spring-ai-starter-model-openai`, and `spring-ai-bom` from `pom.xml`.
  * Verified zero `org.springframework.ai.*` imports across all production and test source files.
* **Unified Model Cache (`UserLlmClientFactory`)**:
  * Eliminated the duplicate `springChatModelCache` in `UserLlmClientFactory.java`.
  * Unified user BYOK decryption (AES-GCM) and default system fallback into a single, synchronized cache managing LangChain4j `ChatModel` and `StreamingChatModel` instances.
  * Added `StreamingChatModel openAiStreamingChatModel()` bean to `LangChainModelConfig.java`.
* **Configuration Centralization**:
  * Consolidated all LLM properties under `auditagent.llm.*` in `LlmProperties.java` and `application-example.yaml`.

### 2. Single Responsibility Principle (SRP) Pipeline Decomposition
* **`ChatConversationService` (`@Primary ChatService`)**:
  * Implements conversational triage, system prompt generation, and command tag injection (`[TRIGGER_FIX:VULN-ID]`, `[TRIGGER_SCAN]`).
  * Provides real-time reactive token streaming using LangChain4j `StreamingChatModel` emitting directly over SSE Flux streams.
  * Implements 2-tier issue matching: fast deterministic regex finding matching followed by LangChain4j semantic matching.
* **`RemediationToolRegistry`**:
  * Declaratively defines all 10 LangChain4j `ToolSpecification` instances (`read_file`, `write_file`, `compile_project`, `run_tests`, `check_syntax`, `rescan_file`, `rollback_file`, `search_code`, `get_file_hash`, `retrieve_approved_memories`).
  * Performs strict argument validation, dispatches execution to `AgentToolService` and `DatabaseService`, classifies execution status (`isSuccessfulToolResult`), flags mutating operations (`isMutatingTool`), and computes SHA-256 idempotency digests.
* **`MemoryReflectionService`**:
  * Asynchronously generates anti-pattern warnings from failed agent trajectories (`reflectOnFailure`) using LangChain4j `ChatModel`.
  * Extracts positive abstract remediation patterns from merged pull request diffs (`summarizeDiffForGlobalPattern`).
* **`LlmTokenAuditService`**:
  * Encapsulates token usage telemetry: registers Micrometer counter metrics (`ai.tokens.consumed`) and persists token audit records to the database.
* **Refactored `LlmService`**:
  * Rebuilt as a clean, high-level facade coordinating multi-turn agent tool execution loops, delegating domain responsibilities to the extracted services.
