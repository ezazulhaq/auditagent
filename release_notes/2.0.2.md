# AuditAgent Release Notes - v2.0.2

## 🚀 Enhancements & Performance Improvements

### TypeSafe AI "System 1" Orchestration (JEV Model Integration)
In this release, we have fundamentally overhauled how the multi-agent Star Topology performs its dynamic routing. To drastically optimize LLM response latency and token costs, the **Supervisor Agent** now utilizes a dedicated "System 1" model (TypeSafe AI's **JEV** model) instead of relying on the general-purpose worker LLM (e.g. Claude 3.5 Sonnet). 

Because JEV is non-autoregressive and built strictly for high-speed, structured decision-making, the orchestration overhead between the 16 worker agents is now exceptionally fast and reliable.

- **Strict JSON Schema & Structured Outputs:** The `SupervisorNode` has been upgraded to leverage LangChain4j's `ResponseFormat.JSON` natively. By enforcing a strict JSON Schema, we eliminated the need to parse raw conversational text for routing decisions, preventing prompt drifts and mapping errors.
- **Dedicated Supervisor LLM Bean:** To support dual-model operation without wiring conflicts, the architecture now features a decoupled, zero-temperature `supervisorChatModel` Bean specifically for routing, while the powerful `@Primary` worker LLM handles the deep code analysis. 

## ⚙️ Configuration Changes

A new configuration property has been added to support the System 1 supervisor model:
- `auditagent.llm.openai.supervisor-model-name`: Defines the model used for routing. Defaults to `typesafe/jev-router` via OpenRouter. 
*(Note: Please refer to `application-example.yaml` to see how this fits alongside your existing `model-name` worker config).*
