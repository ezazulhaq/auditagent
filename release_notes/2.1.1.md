# AuditAgent v2.1.1 Release Notes

**Release Date:** October 27, 2026

AuditAgent 2.1.1 is a developer experience and documentation tooling release introducing the **`doc-navigator`** workspace skill, an executable documentation search utility, structured architectural invariant guides, and synchronized project documentation catalogs across the codebase.

---

## 🚀 New Features & Enhancements

### 1. Developer Workspace Skill: `doc-navigator`
Introduced a specialized workspace skill under `.agents/skills/doc-navigator/` to assist developers and AI coding assistants (such as Antigravity and AGY) when navigating, querying, and verifying context within the AuditAgent documentation suite (`doc/` or `@doc`).

* **Progressive Routing Matrix**:
  * Added a direct topic-to-guide lookup table in `SKILL.md` connecting inquiries across all 17 numbered guides and `doc/README.md` (architecture, backend, frontend, REST APIs, SSE protocols, persistence, security model, operations, troubleshooting, and change recipes).
  * Directs AI assistants to inspect targeted line ranges, preserving LLM context window tokens while ensuring comprehensive factual grounding.
* **Architectural Ground Truth & Invariants**:
  * Establishes strict verification checks against core system invariants:
    * Server-side authenticated session is the sole identity; client-supplied paths and identities are untrusted references.
    * Isolated clones managed by JGit under `AUDITAGENT_WORKSPACE_ROOT`; shared APIs reject arbitrary local paths.
    * GitHub OAuth access/refresh tokens encrypted via AES-GCM `TokenCipher`.
    * Autonomous 16-stage LangGraph4j remediation graph (`SupervisorNode` with recursion limit 150).
    * GitHub webhook reconciliation (`action: closed`, `merged: true`) transitioning vulnerabilities to `FIXED`.
    * PostgreSQL/DuckDB transactional persistence and lexical FTS/BM25 retrieval (no vector DB, no embeddings).
* **Documentation Maintenance Policy Enforcement**:
  * Codifies mandatory documentation synchronization: every code, configuration, rule, schema, or API change must update companion guides in `doc/` within the same change.

### 2. Standalone Documentation Search Utility (`doc-search.sh`)
Bundled an executable, zero-dependency bash search engine at `.agents/skills/doc-navigator/scripts/doc-search.sh` to allow instantaneous search across `doc/*.md`:

* **Full-Text & Heading Search**:
  * Supports full-text substring and regex queries with line numbers.
  * `-H, --headers-only`: Scans only Markdown headings (`#`, `##`, `###`) for rapid chapter and section discovery.
* **Document Filtering & Relevance Counts**:
  * `-f, --file <pattern>`: Scopes search to matching document names (e.g., `-f api` or `-f 07`).
  * `-c, --count-only`: Generates match frequency counts per document to identify primary source guides quickly.
  * `-C, --context <num>`: Displays surrounding context lines for each match.
