# AuditAgent v2.3.3 Release Notes

**Release Date:** November 2, 2026

AuditAgent 2.3.3 introduces a one-click copy action directly beside the vulnerability finding ID in the finding details drawer (`FindingDrawer`), enabling developers to quickly copy finding identifiers (e.g., `VULN-000001`) to the clipboard for chat triage or external ticket referencing. It also enhances the reusable `CopyButton` component with size variants, accessible labeling, and temporary feedback states.

---

## 🚀 New Features & Enhancements

### 1. One-Click Finding ID Copy Action (`FindingDrawer`)
* **Header Integration**: Added a compact copy button directly beside `finding.id` at the top of the finding details drawer between the severity badge and status badge.
* **Instant Feedback**: Clicking the copy button copies the finding ID to the clipboard, providing an immediate visual checkmark and "Copied!" tooltip feedback for 2 seconds.
* **Propagation Safety**: Prevents unintended click bubbling when nested in interactive surfaces via `e.stopPropagation()`.

### 2. Enhanced Reusable `CopyButton` Component (`CopyButton`)
* **Size Variants**: Supported `xs` (11px icon, compact padding), `sm` (12px icon), and `md` (14px icon) variants to fit headers, code snippets, and diff views seamlessly.
* **Accessibility**: Added configurable `aria-label` and `title` attributes with dynamic status announcements for screen readers.
