# AuditAgent v2.4.0 Release Notes

**Release Date:** November 3, 2026

AuditAgent 2.4.0 introduces native integration with TypeSafe AI's **Jev Model** (`typesafe/jev-1.13` via OpenRouter `POST /api/v1/systemone`). This release dramatically cuts LLM inference costs and decision latency by leveraging non-autoregressive decision queries for **Pre-Flight Finding Triage** (filtering false positives and test mocks before multi-agent remediation) and **Supervisor Routing Acceleration** (routing the 15-stage LangGraph4j supervisor with sub-second deterministic choice queries).

---

## 🚀 New Features & Enhancements

### 1. Pre-Flight Finding Triage (`FindingTriageService`)
* **Static Finding Classification**: Evaluates static Semgrep scan findings immediately post-scan using Jev non-autoregressive `noul` and `score` questions to identify false positives, test mocks, and intentional examples.
* **Massive Token & Cost Savings**: Avoids triggering expensive 15-stage multi-agent remediation runs (~50k–150k tokens saved per avoided run) for non-actionable or test-mock findings.
* **Java 21 Virtual Threads**: Executes finding triage in parallel using virtual threads (`Executors.newVirtualThreadPerTaskExecutor()`) to process entire finding sets with minimal overhead.
* **Adaptive Confidence Guardrails**: Applies a dual-threshold confidence guardrail (0.75 standard threshold, 0.95 high-severity threshold) to prevent false-negative dismissals of critical security issues.
* **Database Persistence**: Stores triage metadata (`triage_actionable`, `triage_confidence`, `triage_classification`) in DuckDB alongside vulnerability records.

### 2. Supervisor Routing Acceleration (`SupervisorNode`)
* **Deterministic Choice Routing**: Leverages Jev's `choice` question type over allowed `AgentStage` values (`DISCOVERY`, `SYNTAX`, `BASELINE`, `SECURITY_REVIEW`, `DATA_FLOW`, `RCA`, `VALIDATION`, `COMPLETE`) within the LangGraph4j supervisor.
* **Token Cost & Latency Reduction**: Reduces input token costs by ~98% ($0.042/1M input tokens vs. standard chat model rates, with $0.00 output tokens) and achieves sub-2-second routing decisions.
* **Automatic Graceful Fallback**: Bounded by a 3-second timeout and 1 retry; automatically and seamlessly falls back to standard `ChatModel` if Jev is disabled, times out, or encounters errors.

### 3. Dedicated Jev REST Client (`JevClient`)
* **OpenRouter SystemOne Support**: Implements a dedicated Spring WebClient wrapper communicating with OpenRouter's `/api/v1/systemone` endpoint.
* **Typed Question Primitives**: Full object modeling for Jev `choice`, `noul`, `score`, and `eval` questions, options, and response structures.
* **Configurable Credentials**: Uses dedicated `auditagent.jev.*` properties while cleanly defaulting to existing OpenRouter/OpenAI API credentials.

### 4. UI Indicators & Bulk Remediation Safeguards
* **"Likely FP" Amber Badges**: Displays a clear amber badge on findings flagged as non-actionable in both the main findings table (`FindingsView`) and the finding details drawer (`FindingDrawer`).
* **Pre-Flight Assessment Card**: Surfaces classification rationale, triage confidence score, and actionability status directly within the finding details drawer.
* **Safe Bulk Select-All**: Updates "Select All" logic in `FindingsView` to automatically exclude likely false positives from bulk remediation actions, preventing accidental batch runs on non-actionable code while preserving individual manual remediation controls.

## ⚙️ Configuration Reference

```yaml
auditagent:
  jev:
    enabled: true
    base-url: https://openrouter.ai/api/v1/systemone
    model: typesafe/jev-1.13
    api-key: ${OPENROUTER_API_KEY:${auditagent.llm.openai.api-key:}}
    timeout-seconds: 3
    max-retries: 1
    confidence-threshold: 0.75
    high-severity-threshold: 0.95
```
