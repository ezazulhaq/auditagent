# AuditAgent v2.0.1 Release Notes

**Release Date:** September 30, 2026

AuditAgent 2.0.1 is a feature release that introduces a highly requested capability to manage your security workspace's data footprint and ensure clean reporting.

## 🚀 New Features

### Scan History Clearing
You can now explicitly wipe the scan history for a selected repository and branch directly from the application's UI.

* **Dashboard Integration**: A new "Clear Scan History" button is prominently displayed in the security overview dashboard whenever you have a repository and branch selected.
* **Bulk Data Purge**: Deleting the scan history automatically cascades and purges all related security artifacts for that branch, including:
  * Persistent scan reports
  * Detected vulnerabilities and their status
  * Security score statistics
  * Historical scan snapshots
* **Safety First**: Destructive data actions are protected behind a deliberate confirmation dialog to prevent accidental deletion, and the backend endpoints strictly enforce that the user holds valid read authorization for the targeted GitHub repository before allowing the wipe.
