# AuditAgent v2.13.1 Release Notes

**Release Date:** November 19, 2026

AuditAgent 2.13.1 introduces in-app version visibility directly inside the header menu and synchronizes version descriptors across backend and frontend codebases. This release dynamically embeds the application version from `package.json` in the user profile dropdown menu beside the Sign out action at its rightmost end, providing immediate version clarity for operators and users.

---

## 🚀 New Features & Enhancements

### 1. Header Menu Version Indicator
* **Dynamic Version Display (`AppHeader.jsx`)**:
  * Sourced the application version directly from `frontend/package.json` (`import packageJson from '../../package.json'`).
  * In the header's user profile menu, arranged the bottom action section into a flex container (`flex items-center justify-between`) containing the **Sign out** button on the left and a version badge (`v{packageJson.version}`) aligned to the rightmost end.
  * Styled the badge consistently with existing design tokens (`text-[10px] font-mono text-[var(--text-muted)] border border-[var(--border-subtle)] bg-[var(--surface-inset)] rounded px-1.5 py-0.5 select-none mr-3`), ensuring visual harmony with the theme mode indicator.

### 2. Header Component Testing
* **Automated Unit Tests (`AppHeader.test.jsx`)**:
  * Added unit tests for `AppHeader` covering workspace branding, file scan metadata, user dropdown menu toggling, Sign out trigger execution, and verification that the version badge displays the exact version from `package.json`.
