# AuditAgent v2.14.2 Release Notes

**Release Date:** November 22, 2026

AuditAgent 2.14.2 migrates all runtime remediation skills from `.auditagent/skills/` to `src/main/resources/skills/` with native Spring Boot classpath compatibility, implements dynamic resource pattern loading in `SkillManagerService`, and introduces dedicated skills environment configuration options.

---

## 🚀 Enhancements & Architecture Refactoring

### 1. Spring Boot Classpath Skills Migration
* **Runtime Resource Relocation**:
  * Migrated 20 code review stage playbooks and remediation skills from the host filesystem path `.auditagent/skills/` to `src/main/resources/skills/`.
  * Skills are now bundled directly within the packaged Spring Boot executable JAR (`BOOT-INF/classes/skills/`), eliminating host filesystem path dependencies in production container environments.
* **Dynamic Spring ResourcePatternResolver**:
  * Refactored `SkillManagerService` to discover skills using Spring's `ResourcePatternResolver` matching `classpath*:skills/**/SKILL.md`.
  * Replaced direct `java.io.File` read operations with stream-based UTF-8 reading (`resource.getInputStream()`) to avoid `FileNotFoundException` inside packaged archives.
  * Added configurable properties with environment variable bindings:
    * `auditagent.skills.location` (`AUDITAGENT_SKILLS_LOCATION`, default: `classpath:skills/`)
    * `auditagent.skills.pattern` (`AUDITAGENT_SKILLS_PATTERN`, default: `classpath*:skills/**/SKILL.md`)
    * `auditagent.skills.fallback-dir` (`AUDITAGENT_SKILLS_FALLBACK_DIR`, default: `.auditagent/skills`)
  * Preserved automatic filesystem fallback to `.auditagent/skills` for backwards compatibility.

### 2. Configuration & Environment Modernization
* **Environment Template (`.env.example`)**: Added dedicated `4c. Runtime Remediation Skills & Prompt Playbooks` section with `AUDITAGENT_SKILLS_*` options.
* **Spring Configuration Overlays**: Updated `application-example.yaml`, `application-dev.yaml`, and `application-local.yaml` with `auditagent.skills` property blocks.
* **IDE Configuration Metadata**: Updated `additional-spring-configuration-metadata.json` for autocomplete and validation.
* **Container Build & Composition**: Updated `Dockerfile`, `Dockerfile.dev`, `docker-compose.yml`, and `docker-compose-dev.yml` to reflect JAR-bundled skills.
