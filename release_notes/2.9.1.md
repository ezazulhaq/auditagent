# AuditAgent v2.9.1 Release Notes

**Release Date:** November 15, 2026

AuditAgent 2.9.1 is a patch release addressing finding reconciliation and persistence stability following Phase 2 database hardening. It resolves an issue where previously resolved vulnerabilities persisted in the normalized `vulnerabilities` table and reappeared upon subsequent repository loads or user logins, ensuring report findings accurately reflect the active vulnerabilities detected by the latest security scan.

---

## 🛠️ Defect Fixes & Improvements

### Finding Lifecycle Reconciliation & Pruning
* **Prune Omitted & Resolved Findings**:
  * In `ScanDataService.saveReport()`, the persistence pipeline now identifies existing database finding records for the repository branch whose fingerprints are omitted from the active scan and deletes them in chunked batches (`vulnerabilityEntityRepository.deleteAllById()`).
  * Resolves stale findings lingering in DuckDB/PostgreSQL after code remediation, pull request merges, or subsequent rescans.
* **Non-Null Finding Guarantees**:
  * In `ScanDataService.mapToReport()`, ensured reports with 0 active findings default cleanly to an empty list (`new ArrayList<>()`) instead of `null`, preventing downstream `NullPointerException` risks during report export, serialization, or chat context generation.
* **Automated Regression Test Suite**:
  * Added `testRescanPrunesResolvedVulnerabilitiesFromReportAndDatabase()` in `ScanDataServiceBatchUpsertTest.java` to verify that rescan execution cleanly prunes resolved findings from both the report payload and the database table.
